# Grounding demo image

`pointing-demo.jpg` is a compressed copy of PxHere image 899556, released under
CC0 Public Domain. The source page is https://pxhere.com/en/photo/899556.

`pointing-demo-int4-result.png` and `pointing-demo-int8-result.png` are derived
copies showing the points returned by the corresponding checkpoints.

The image is also part of the public PointBench evaluation data. It is included
here solely to make each Hugging Face model card's inference example complete
and reproducible without an external image download.
